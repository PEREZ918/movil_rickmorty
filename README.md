# Rickverse - Rick and Morty Hub 🌌

**Rickverse** es una aplicación Android moderna construida con **Jetpack Compose** que consume la API de Rick and Morty para explorar los personajes y episodios del multiverso.

## 🚀 Características actuales
- **SplashScreen Dinámico**: Animación de portal con estilo neon.
- **HomeScreen**: Interfaz futurista con buscador de dimensiones, elenco principal y lista de episodios.
- **Arquitectura MVVM**: Separación clara entre capas de datos y UI.
- **Material 3**: Uso de componentes y temas modernos.

## 🛠️ Tecnologías utilizadas
- **Kotlin**: Lenguaje principal.
- **Jetpack Compose**: UI declarativa.
- **Retrofit & Gson**: Consumo de servicios REST.
- **Coil**: Carga eficiente de imágenes.
- **Lifecycle & ViewModel**: Gestión de estados de pantalla.
- **Navigation Compose**: Flujo de navegación entre pantallas.

## 📂 Estructura del Proyecto
- `data/`: Modelos, API remota y Repositorios.
- `ui/`: Pantallas (`screens`), componentes reutilizables (`components`) y temas (`theme`).
- `navigation/`: Configuración del grafo de navegación.

## 📥 Cómo ejecutar el proyecto
1. Clonar el repositorio.
2. Abrir en **Android Studio Ladybug** o superior.
3. Sincronizar Gradle.
4. Ejecutar `./gradlew assembleDebug` para compilar.
